Proses Membuat Website Toko Batik

Website Toko Batik merupakan proyek yang saya buat untuk melatih kemampuan membangun aplikasi web dari sisi tampilan hingga pengelolaan data.

Proses pengerjaan dimulai dengan menentukan kebutuhan utama, yaitu katalog produk yang mudah dilihat pengunjung dan halaman admin untuk mengelola data. Saya menggunakan Bootstrap untuk membantu membuat tampilan responsif serta PHP dan MySQL untuk memproses dan menyimpan data produk.

Dari proyek ini saya belajar bahwa website tidak hanya harus terlihat menarik, tetapi juga perlu memiliki struktur yang jelas dan mudah digunakan. Saya juga belajar memeriksa kembali tampilan pada berbagai ukuran layar serta memperbaiki kendala yang muncul selama proses pengembangan.
